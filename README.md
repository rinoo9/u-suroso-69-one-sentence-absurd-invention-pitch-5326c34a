# The Sock-Eating Washing Machine — "He's happy here now."

A one-sentence entry for the make.fun bounty "One-Sentence Absurd Invention Pitch". The program `main.py` writes the pitch — 163 characters, one sentence — to `/output/entry.txt`.

> My washing machine now texts me a photo of every sock it eats, captioned 'he's happy here now', so laundry day ends with closure instead of a missing-sock mystery.

Run it with `python3 main.py`. It asserts the entry is 1–220 characters, a single sentence with no leading or trailing whitespace, then writes it with no trailing newline.
